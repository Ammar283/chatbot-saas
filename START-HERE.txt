QUICK START
===========

1. Open a terminal in this folder and run:

     npm install


2. Copy .env.example to a new file named .env

     Windows:    copy .env.example .env
     Mac/Linux:  cp .env.example .env


3. Open .env and fill in at minimum these seven values:

     LLM_BASE_URL=https://api.groq.com/openai/v1
     LLM_API_KEY=gsk_your_groq_key_here
     LLM_MODEL=llama-3.3-70b-versatile

     ADMIN_KEY=any-long-random-string
     SESSION_SECRET=a-different-long-random-string
     OWNER_EMAIL=you@yourcompany.com
     OWNER_PASSWORD=a-password-you-will-remember

   Each line must be NAME=value. No quotes, no spaces around the =,
   and the name must appear only once.


4. Start it:

     npm start

   You should see "Owner account created: you@yourcompany.com"
   followed by three URLs.


5. Open http://localhost:3000/login.html

   Sign in with the OWNER_EMAIL and OWNER_PASSWORD you just set.


6. In the dashboard sidebar click "+ New workspace", give it a
   business name, then go to Knowledge and read a real website.


7. Go to Settings, copy the pk_ key from the install snippet, and
   open http://localhost:3000/demo.html?key=pk_...

   Ask it a question. A real answer means everything is connected.


FOLDER LAYOUT
=============

  server.js           the whole HTTP server
  lib/                retrieval, prompting, auth, notifications, health
  public/             login page, dashboard, chat widget, demo page
  scripts/backup.js   snapshot and restore
  data/               created at runtime; holds all client data

  A correct install has 8 files in lib/, 4 in public/, 1 in scripts/.
